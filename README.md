# Metal Rage Reborn

A personal game development project around **Metal Rage Online**.

Metal Rage Online is a mech third-person shooter whose official service ended in 2011. This project studies how the game client works and documents it, so the knowledge is not lost. It is non-commercial.

- Project page: https://luca5764.github.io/metal-rage-reborn/
- Notes, grouped by topic:
  - [How to read these notes](how-to-read.md)
  - [Battles & multiplayer](battles-multiplayer.md)
- Support the project: https://ko-fi.com/lucasu

## What is here

Documentation only. This repository has no server code, launcher code or game files.
